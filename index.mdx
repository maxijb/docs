BitSetJS gives you a fast, memory-efficient `BitSet` class for JavaScript. Whether you need to track feature flags, permission sets, or any large collection of on/off values, BitSetJS packs your bits into 32-bit integers so you use a fraction of the memory of a plain boolean array.

## What is a BitSet?

A `BitSet` is an ordered array of bits — each element is either `0` (false) or `1` (true). BitSetJS stores those bits compactly inside 32-bit integers, so a 1000-bit array uses just 32 integers instead of 1000 individual values.

```javascript
import BitSet from 'bit-set-js';         // ES6 / CommonJS

const flags = new BitSet(8);             // 8-bit array, all 0s
flags.set(0);                            // turn on bit 0
flags.set(3);                            // turn on bit 3
console.log(flags.stringify());          // "00001001"
console.log(flags.count());             // 2
```

<Steps>
  <Step title="Install the library">
    ```bash
    npm install bit-set-js
    ```
  </Step>
  <Step title="Create a BitSet">
    ```javascript
    const BitSet = require('bit-set-js');
    const bits = new BitSet(32);
    ```
  </Step>
  <Step title="Manipulate bits">
    ```javascript
    bits.set(5);
    bits.toggle(10);
    console.log(bits.get(5));   // true
    ```
  </Step>
  <Step title="Serialize and transfer">
    ```javascript
    const binary = bits.stringify();   // "00000000000000000000010000100000"
    const ints   = bits.getData();     // [1056]
    ```
  </Step>
</Steps>
